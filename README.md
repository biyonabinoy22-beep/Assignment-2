# Excel Data Cleaning Project

This project focuses on cleaning, standardizing, and formatting a product dataset using **Microsoft Excel**.

### Tasks Performed
- Handled missing values in **Price** and **Category** columns.
- Corrected inconsistent product names and category typos.
- Identified and removed duplicate rows.
- Split **Product ID** into **Manufacturing Date** and **Country Code**.
- Merged **Brand Name** and **Product Name** into **Product Brand**.
- Applied currency and date formatting.
- Used conditional formatting to visualize **Price** and highlight **Electronics** categories.

### Objective
To improve the **accuracy, consistency, and usability** of the dataset through practical Excel data-cleaning techniques.
